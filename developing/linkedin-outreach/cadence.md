# Cadence — Aanloop AI LinkedIn Outreach

Dag- en weekritme voor handmatige outreach. Doel: consistent, veilig binnen
LinkedIn-limieten, en afgestemd op de content-kalender.

## Veilige limieten (handmatig)

| Actie | Limiet | Reden |
|---|---|---|
| Connection-requests | max ~20-25 / dag | Boven ~100/week stijgt schorsingsrisico |
| Berichten (DM's) | max ~30-40 / dag | Spread over de dag, niet in burst |
| Profielbezoeken | onbeperkt redelijk | Bezoek prospect vóór request (warmt op) |

Nieuw of weinig-actief account? Start lager (~10/dag) en bouw 2 weken op.

## Dagritme (≈45-60 min/dag)

1. **Ochtend (15 min)** — 10-12 connection-requests (template 1).
2. **Midden (15 min)** — opvolgberichten: geaccepteerde connecties → template 2;
   lopende gesprekken → template 3/4.
3. **Eind dag (15 min)** — CSV bijwerken (`status`, `laatste_actie`,
   `datum_contact`), follow-ups inplannen, 10 nieuwe prospects opzoeken.

## Weekritme — afgestemd op content-kalender

Content-posts staan op **ma / wo / do 09:00 CET**
(`marketing/linkedin/wave-1-schedule.json`). Outreach bij voorkeur ná de
ochtendpost, zodat een benaderde prospect een actief profiel ziet.

| Dag | Focus |
|---|---|
| Maandag | Post live → nieuwe requests (verse week, hoge acceptatie) |
| Dinsdag | Requests + opvolgen geaccepteerde connecties |
| Woensdag | Post live → requests + waardeberichten |
| Donderdag | Post live → afspraak-vragen (template 4), gesprekken |
| Vrijdag | Follow-ups (template 5) + CSV-opschoning + weekreview |

## Eisenhower-indeling

| Kwadrant | Taak |
|---|---|
| **Q1** urgent + belangrijk | Reageren op binnengekomen reacties/afspraakverzoeken (< 24u) |
| **Q2** belangrijk, niet urgent | Dagelijkse requests, prospectlijst vullen, content afstemmen |
| **Q3** urgent, niet belangrijk | Generieke connectieverzoeken zonder fit → delegeren/skippen |
| **Q4** elimineren | Outreach-automatiseringstools, bulk-mailen, ongepersonaliseerd spammen |

Kern: Q2 is de motor — elke dag dezelfde discipline. Q1 gaat altijd vóór Q2
op de dag zelf (warme lead nooit laten afkoelen).

## Maandelijkse review

- Acceptatie- en reactieratio per persona/sector vergelijken → beste segment opschalen.
- Slechtst presterende template herschrijven.
- `status = klant` tellen → outreach-ROI.
