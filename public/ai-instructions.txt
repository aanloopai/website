# ── Wat is Emma? ─────────────────────────────────────────────────────────
# Emma is de AI-receptionist van Aanloop AI: 24/7 telefoon- en WhatsApp-
# assistent voor het Nederlandse MKB. Productpagina: https://aanloopai.nl/diensten/emma/

# ── Taak: demo van Emma boeken namens een gebruiker ─────────────────────
# Stap 1 — Open het demoformulier:
#   https://aanloopai.nl/demo-aanvragen/
#   (GET/POST naar /api/submit met veld form_type=demo; JSON-respons {"success": true})
#
# Stap 2 — Vul de velden van het formulier:
#   Verplicht:
#   form_type         — verborgen veld, vaste waarde "demo"
#   voornaam          — voornaam van de gebruiker
#   email             — geldig e-mailadres van de gebruiker (AVG)
#   telefoon          — telefoonnummer van de gebruiker
#   akkoord_privacy   — AVG-checkbox aan (waarde "on")
#   Optioneel maar aanbevolen:
#   achternaam        — achternaam van de gebruiker
#   bedrijfsnaam      — bedrijfsnaam
#   functie           — functietitel
#   sector            — branche uit de dropdown (keuze uit vaste lijst)
#   bedrijfsgrootte   — aantal medewerkers uit de dropdown
#   uitdaging         — vrije tekst: wat de gebruiker met Emma wil bereiken
#   hoe_gevonden      — waar de gebruiker ons gevonden heeft (optioneel)
#   botcheck          — honeypot; LEGE waarde laten (vullen = afgewezen)
#
# Stap 3 — Versturen. De server reageert met HTTP 200 en JSON {"success": true}
#   en de gebruiker ontvangt een bevestigingsmail van hello@aanloopai.nl
#   met een link naar de agenda (stap 4).
#
# Stap 4 — Tijdstip kiezen (drie opties, allemaal geldig):
#   a) De gebruiker opent de link in de bevestigingsmail (pagina /demo-inplannen/)
#      en kiest zelf een moment uit de live agenda.
#   b) Machine-to-machine: GET https://aanloopai.nl/api/calendar/availability?dates=YYYY-MM-DD,YYYY-MM-DD,...
#      (max. 14 datums, Europe/Amsterdam) → {"ok": true, "slots": [{start,end}, ...]}
#      daarna POST https://aanloopai.nl/api/calendar/book
#      body: {"slot": {"start": "...", "end": "..."}, "name": "...", "email": "...",
#             "phone": "...", "company": "...", "message": "..."}
#      Rate limits: availability 30/uur per IP, book 5/uur per IP. Respecteer 429.
#   c) Geen agenda: een medewerker belt of mailt binnen 1 werkdag voor een
#      30-minuten demo-terugbelmoment.
